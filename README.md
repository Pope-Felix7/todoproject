# ✓ TodoApp – Django & Bootstrap Todo List

A full-featured todo list web application built with Django and Bootstrap 5.

## Quick Start

```bash
# 1. Install dependencies
pip install django

# 2. Run migrations
python manage.py migrate
1. .\myvenv\Scripts\Activate.ps1
2. python manage.py runserver

# 3. (Optional) Create admin user
python manage.py createsuperuser

# 4. Start the server
python manage.py runserver

# 5. Open browser at http://127.0.0.1:8000/
```

## Features
- User Registration & Login
- Dashboard with task statistics
- Create, Edit, Delete, Toggle tasks
- Priority levels (High / Medium / Low)
- Color-coded categories
- Due dates with overdue detection
- Filter & search tasks
- User profile with avatar color
- Change password
- Django Admin panel

## Tech Stack
- **Backend:** Django 4.x (Python)
- **Frontend:** Bootstrap 5 + Bootstrap Icons
- **Database:** SQLite (dev) / PostgreSQL (prod)
- **Architecture:** Function-Based Views (FBV)
